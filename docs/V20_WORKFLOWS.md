# V20 Workflows

## Provider
Login → My Patients → Full Patient Workspace → Summary / Mobile / XR / Monthly Activity / Provider Activity / Communication / Billing / Insights.

## Admin
Organization Overview → Patients / Providers / Provider Time / Explorer / Engagement / Modules / Platform / Billing & RTM / Audit.

## Billing Reviewer
Billing & RTM Review → Patients tab or Providers tab → exact provider-time evidence → provider drill-down or patient PDF.

## Billing evidence
`DATA_REVIEW + COMMUNICATION + DOCUMENTATION = Total Provider Time` for one patient/month.

The optional synthetic dollar amount is a demo visualization only and is not an insurance or Medicare reimbursement determination.
